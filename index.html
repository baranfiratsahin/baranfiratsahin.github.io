fsahin.com — World Terminal

A single-screen, real-time command surface for the planet. It renders live signals from public scientific and civic data providers on one interactive map: earthquakes, wildfires, aircraft, the ISS, markets, space weather and news. Hand-written vanilla JavaScript running against a single Cloudflare Worker — no framework, no build step, no page builder.

The design rule is real data, honest failure: every value resolves to a live source, and when a feed dies the interface prints SIGNAL LOST instead of inventing a number.
